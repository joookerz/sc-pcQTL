# Third-party software

sc-pcQTL orchestrates Nextflow, R, fasthurdle, SAIGE-QTL, and PLINK. Their
source code and licenses remain governed by their upstream projects. The
container definitions in this repository record the exact fasthurdle commit
and SAIGE-QTL image used by the workflow.

- Nextflow: https://github.com/nextflow-io/nextflow
- fasthurdle: https://github.com/mkanai/fasthurdle
- SAIGE-QTL: https://github.com/weizhou0/qtl
- PLINK 1.9: https://www.cog-genomics.org/plink/1.9/
